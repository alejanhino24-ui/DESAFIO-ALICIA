# DESAFIO-ALICIA
# Alicia en el país de las maravillas

## 1. Descripción del proyecto

Página web interactiva inspirada en *Alicia en el país de las maravillas*, desarrollada para la materia Programación Web I. Contiene tres ejercicios que aplican lógica de programación mediante formularios HTML, estilos CSS y JavaScript.

## 2. Ejercicios implementados

1. **La poción mágica de Alicia:** calcula la altura final de Alicia según la cantidad de poción.
2. **La merienda del Sombrerero Loco:** calcula el costo de las bebidas y aplica descuentos cuando corresponde.
3. **El desafío de la Reina de Corazones:** analiza números pares e impares y compara sus sumas.

## 3. Tecnologías utilizadas

- HTML5: estructura y formularios.
- CSS3: diseño visual y presentación.
- JavaScript: funciones, estructuras de control, DOM, eventos, cálculos y validación de datos.

## 5. Evidencias y pruebas

La carpeta `evidencias/capturas/` contiene las capturas de pantalla de los tres ejercicios funcionando.

El archivo `evidencias/casos-de-prueba.pdf` contiene los casos de prueba utilizados para comprobar los resultados y la validación de los datos.

## 6. Cómo ejecutar el proyecto

1. Descarga o clona el repositorio.
2. Mantén `index.html`, `estilos.css` y `script.js` en la misma carpeta.
3. Abre `index.html` en un navegador web.
